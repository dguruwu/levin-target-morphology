## CLAIM 1: Cells hold memory of the target morphology (the stored counterfactual).

RECEIPT: "Target morphology and cell memory: a model of regenerative pattern formation."
Bessonov N, Levin M, Morozova N, Reinberg N, Tosenberger A, Volpert V.
Neural Regeneration Research, 2015 Dec;10(12):1901-5. PMID 26889161. PMCID: PMC4730797. DOI: 10.4103/1673-5374.165216.
Abstract (fetched): cells "keep the value of the total signal received from the other cells"; amputation changes the signal distribution; "the difference from the original signal distribution stimulates cell proliferation... in effect implementing an error minimization process that uses signaling memory to achieve pattern correction." The paper's named open question: "what mechanisms implement recognition of correct morphology that signals a stop condition."
